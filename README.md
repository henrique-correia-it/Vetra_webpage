# Vetra — Website Oficial & Política de Privacidade

Este repositório contém a página web e a Política de Privacidade pública da aplicação móvel **Vetra**.

## Ficheiros
- `index.html`: Página de apresentação da aplicação Vetra.
- `privacy.html`: Política de Privacidade oficial em conformidade com o Google Play e o RGPD.
- `assets/`: Ícones e recursos visuais da marca Vetra.

## Publicação no GitHub Pages
1. Crie um repositório no GitHub (ex.: `Vetra_webpage` ou `vetra-privacy`).
2. Adicione este repositório como `remote origin` e faça push da branch `main`.
3. No GitHub, vá a **Settings** > **Pages** > **Build and deployment** > Source: **Deploy from a branch** (Branch: `main`, pasta `/root`).
4. O link público ficará disponível em:
   `https://<teu-utilizador>.github.io/<nome-do-repositorio>/privacy.html`
